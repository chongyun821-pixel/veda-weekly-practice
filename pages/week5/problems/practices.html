문제 1. 3의 배수 처리 코드

아래 ARM 코드는 R0와 R1를 이용해 반복문을 돌면서 특정 시점에 multiple_of_3 라벨로 분기합니다. 이때 3의 배수를 찾았을 때 코드가 실제로 하는 동작을 가장 적절하게 고르세요.

.global _start
.text
_start:
    MOV R0, #1
    MOV R1, #1

loop:
    CMP R0, #101
    BEQ end_program

    CMP R1, #3
    BEQ multiple_of_3

    ADD R0, R0, #1
    ADD R1, R1, #1
    B loop

multiple_of_3: @3의 배수 숫자 처리
    ADD R0, R0, #1
    MOV R1, #1
    B loop

end_program:
    BX LR

핵심은 3의 배수를 찾았을 때 출력이나 종료가 아니라, 다음 반복을 위해 레지스터를 어떻게 갱신하는지 읽는 것입니다.
