Tailscale 연결 가이드

Tailscale 이란?

WireGuard 기반의 VPN 서비스로, 같은 계정의 기기들을 하나의 로컬 네트워크처럼 사용할 수 있게 가상의 주소를 부여합니다. 복잡한 포트 포워딩 없이도 외부에서 내 기기에 안전하게 접속할 수 있습니다.

윈도우(Windows) 설치

다운로드 링크

Tailnet에 로그인

설치 후 Tailscale을 실행합니다. 처음 실행하면 인증 URL이 출력되며, 이 URL을 브라우저에서 열어 PC를 계정에 연결합니다. 명령 프롬프트(CMD)에서 아래 명령어를 사용할 수도 있습니다.

tailscale up

리눅스(Linux/Raspberry Pi) 설치

라즈베리파이 터미널에서 아래 명령을 실행하여 설치를 진행합니다.

curl -fsSL https://tailscale.com/install.sh | sh

Tailnet에 로그인

설치 후 아래 명령어를 입력하여 서비스를 활성화합니다. 출력되는 인증 URL을 브라우저에서 열어 Pi를 연결하세요.

sudo tailscale up
💡 팁: Tailscale SSH 활성화
별도의 SSH 설정 없이 Tailscale 네트워크를 통해 보안 접속을 하고 싶다면 아래 명령어를 추가하세요. 
sudo tailscale set --ssh

접속 주소 확인 방법

터미널에서 ip addr 명령어를 실행하여 할당된 Tailscale IP를 확인합니다.

cheongwoo@Rappa:~ $ ip addr
...
4: tailscale0: <POINTOPOINT,MULTICAST,NOARP,UP,LOWER_UP> mtu 1280...
    link/none
    inet 100.99.23.10/32 scope global tailscale0
    ...

위 예시와 같이 tailscale0 항목의 inet 뒤에 오는 100.X.X.X 주소를 사용하면 됩니다.
