GGUF 모델용 Modelfile 자동 생성

현재 디렉토리의 *.gguf 파일을 찾아 절대 경로를 만들고, FROM 절대경로/파일명 한 줄을 Modelfile에 저장하는 Bash 스크립트를 완성해보세요.

작업 위치 /Users/cwohk/models/Hyperclova
대상 파일 HyperCLOVAX-SEED-Omni-8B-Q4_K_M.gguf
핵심 문법 배열, 조건문, 리디렉션, printf

문제. 빈칸을 채워 스크립트 완성하기

현재 디렉토리에 있는 GGUF 모델 파일을 배열로 담고, 첫 번째 모델 파일 경로를 사용해 Modelfile을 생성해야 합니다.

목표 결과: FROM /Users/cwohk/models/Hyperclova/HyperCLOVAX-SEED-Omni-8B-Q4_K_M.gguf 
#!/bin/bash

shopt -s 
current_dir="$( -P)"
models=("${current_dir}"/*.gguf)

if [ "${#models[@]}" -eq 0 ]; then
    echo "현재 디렉토리에 .gguf 파일이 없습니다."
    exit 1
fi

model_file="${models[0]}"
 'FROM %s\n' "$model_file" > 

echo "Modelfile 생성 완료"
cat Modelfile
#!/bin/bash

shopt -s nullglob
current_dir="$(pwd -P)"
models=("${current_dir}"/*.gguf)

if [ "${#models[@]}" -eq 0 ]; then
    echo "현재 디렉토리에 .gguf 파일이 없습니다."
    exit 1
fi

model_file="${models[0]}"
printf 'FROM %s\n' "$model_file" > Modelfile

echo "Modelfile 생성 완료"
cat Modelfile
