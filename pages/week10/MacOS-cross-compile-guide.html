개발 환경 설정 가이드

MacOS 라즈베리파이 크로스 컴파일 가이드

MacOS에서 zig cc 컴파일러를 활용하여 라즈베리파이(aarch64-linux-gnu)용으로 크로스 컴파일하는 과정을 소개합니다.

1. 개요

크로스 컴파일 자체는 gcc 대신 zig cc -target aarch64-linux-gnu 명령어를 사용하면 비교적 쉽게 진행됩니다. 하지만 라즈베리파이의 하드웨어를 제어하기 위해서는 wiringPi 라이브러리가 필수적이므로, 라즈베리파이에 설치된 헤더 파일과 라이브러리를 맥(Mac)으로 복사해 와야 합니다.

💡 Homebrew로 zig 설치하기

MacOS에서는 Homebrew를 이용해 간편하게 zig를 설치할 수 있습니다.

brew install zig

📌 zig cc의 구조적 특징과 Sysroot 구성

일반적인 gcc-aarch64-linux-gnu 같은 크로스 컴파일러 툴체인을 설치하면 보통 /usr/aarch64-linux-gnu/lib와 같이 외부 라이브러리를 넣을 수 있는 명확한 타겟 폴더가 존재합니다.

하지만 zig cc는 그런 방식을 사용하지 않습니다. zig는 내부적으로 glibc, musl 등의 다양한 표준 라이브러리 소스를 고유의 구조로 쪼개서(libc, include 등으로) 들고 있다가, 컴파일하는 순간에 필요한 타겟에 맞춰 동적으로 가상 루트(Sysroot)를 조합하여 ~/.cache/zig/ 같은 곳에 임시로 만들어냅니다. 따라서 wiringPi와 같은 외부 라이브러리를 직접 욱여넣을 고정된 타겟 폴더가 없으므로 별도의 로컬 폴더를 만들어 참조해야 합니다.

2. 로컬 디렉토리에 Sysroot 구성하기

임의의 사용자 폴더(예: ~/clib/aarch64-linux-gnu)에 관련 파일들을 복사해 두고, 컴파일할 때마다 해당 경로를 명시적으로 참조하는 방식으로 진행합니다.

라즈베리파이에서 파일 가져오기

# 헤더 파일 복사
scp -r <계정>@<RPI주소>:/home/<계정>/WiringPi/debian-template/wiringPi/usr/include .
sudo cp -a include/* ~/clib/aarch64-linux-gnu/include/

# 라이브러리 복사
scp -r <계정>@<RPI주소>:/home/<계정>/WiringPi/debian-template/wiringPi/usr/lib .
sudo cp -a lib/* ~/clib/aarch64-linux-gnu/lib/

# crypt 라이브러리 복사 (wiringPi 라이브러리에서 필요함)
scp -r <계정>@<RPI주소>:/usr/lib/aarch64-linux-gnu/libcrypt.so .
sudo cp -a libcrypt.so ~/clib/aarch64-linux-gnu/lib/

컴파일 실행

위에서 구성한 경로를 포함시켜 다음과 같이 컴파일할 수 있습니다. 매번 경로를 입력하는 것이 번거롭다면 환경 변수로 등록하여 사용할 수도 있습니다.

# 기본 컴파일 시 (wiringPi 라이브러리를 직접 링크하는 경우)
zig cc -target aarch64-linux-gnu -I. -I~/clib/aarch64-linux-gnu/include -L~/clib/aarch64-linux-gnu/lib main.c -o main -lwiringPi -lcrypt

# 동적 라이브러리(dlopen)와 pthread를 사용하는 main.c 컴파일 시
zig cc -target aarch64-linux-gnu -I. -I~/clib/aarch64-linux-gnu/include -L~/clib/aarch64-linux-gnu/lib main.c -o main -ldl -lpthread
